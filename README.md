# 가치투자 프로세스

아이디어 발굴부터 복기까지, 개인 가치투자 프로세스(0~8단계)를 실제로 지키도록 돕는 로컬 웹앱입니다.

- 종목이 단계를 차례로 통과합니다: 아이디어 → 1차 필터 → 심층 분석 → 가치평가 → 투자 메모 → 매수 대기 → 보유 → 매도 → 복기 완료. 별도 상태로 탈락이 있습니다.
- 각 단계의 판단을 기록으로 남깁니다. 투자 메모를 확정하면 그 시점의 가치평가와 주가가 고정되어, 복기 때 사후확증편향 없이 비교할 수 있습니다.
- 자동매매나 주문 기능은 없습니다. 기록과 판단을 돕는 도구입니다.

## 설치와 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
cp .env.example .env
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

`.env` 설정은 다음과 같습니다.

| 변수 | 용도 |
|---|---|
| `DART_API_KEY` | 한국 종목 재무제표·공시 수집. https://opendart.fss.or.kr 에서 무료로 발급합니다. |
| `SEC_USER_AGENT` | 미국 종목 수집. API 키는 없고, `"이름 이메일"` 형식의 연락처를 넣습니다(따옴표 포함). |
| `DATABASE_PATH` | 데이터 파일 위치. 기본값은 `./data/app.db`입니다. |
| `IMPORT_API_TOKEN` | 설정하면 `POST /api/candidates`에 Bearer 토큰이 필요합니다. |

## 사용 흐름

1. **투자 원칙** (0단계): 스타일, 능력의 범위, 위험 한도(종목·산업 비중, 종목당 최대 손실)를 정합니다. 바꿀 때마다 버전이 남습니다.
2. **종목 추가** (1단계): 한 종목씩 추가하거나 **후보 가져오기**(CSV, `POST /api/candidates`)로 한꺼번에 넣습니다. 관심 가격 구간을 정하면 대시보드에 알림이 뜹니다.
3. **1차 필터** (2단계): 예/아니오 체크리스트를 채웁니다. 한국 종목은 "자동 체크 실행"으로 DART의 감사의견, 증자·CB, 최대주주 변동을 확인합니다. 자동 결과는 직접 확인한 뒤 적용합니다.
4. **심층 분석** (3단계): 사업 이해, 경쟁우위, 경영진·지배구조를 서술하고 점수를 매깁니다. 재무 탭에서 DART나 SEC로 10년치와 12개 분기를 수집하거나, 엑셀 표를 붙여넣습니다. 체크리스트 탭에서 필립 피셔 15개 질문 같은 템플릿을 적용합니다.
5. **가치평가** (4단계): DCF, PER, EV/EBIT, 자산가치 중 대표 방법을 고르고 비관·기본·낙관 시나리오를 입력합니다. 역DCF로 시장이 가정하는 성장률을 확인합니다.
6. **투자 메모** (5단계): 핵심 논리, 시장의 오해, 촉매, 프리모템, 매도 조건을 쓰고 **확정**합니다. 확정본은 고칠 수 없고, 수정은 새 버전으로만 합니다.
7. **매매·비중** (6단계): 비중 도우미가 원칙의 손실 한도와 비관 시나리오로 상한을 계산합니다. 매매를 기록하면 **포트폴리오** 화면에서 비중과 노출도를 보여 줍니다. 환율과 현금은 포트폴리오 화면에서 입력합니다.
8. **보유 점검** (7단계): 분기마다 논리 상태를 점검하고, 매도 조건 자동 평가를 확인한 뒤 결정을 기록합니다. 100일이 지나면 대시보드에 "점검 필요"가 뜹니다.
9. **복기** (8단계): 매도 후 메모 원본과 실제 결과를 비교합니다. 2×2(실력, 운, 불운, 실수)로 분류하고 실수 태그를 붙입니다. 교훈은 버튼 하나로 원칙이나 1차 필터 체크리스트에 반영됩니다.

단계 이동에는 게이트가 있습니다. 조건을 못 채우면 경고가 뜨고, 그래도 진행하려면 우회 사유를 남겨야 합니다. 우회 기록은 대시보드와 복기 화면에 남습니다.

## 데이터와 백업

- 모든 데이터는 `data/app.db`(SQLite) 하나에 있습니다.
- **설정 → 백업과 내보내기**에서 다음을 할 수 있습니다.
  - 전체 JSON 백업을 받습니다.
  - 백업에서 복원합니다. 복원 직전 상태는 `data/backups/`에 자동으로 저장됩니다.
  - 종목, 매매, 포트폴리오, 복기를 CSV로 받습니다. 엑셀에서 한글이 깨지지 않습니다.
- 종목별 재무 데이터 CSV는 재무 화면에서 받습니다. 받은 파일을 그대로 다시 붙여넣을 수 있습니다.
- 투자 메모는 버전별로 마크다운으로 내보낼 수 있습니다.
