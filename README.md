# 가치투자 프로세스

아이디어 발굴부터 복기까지, 개인 가치투자 프로세스(0~8단계)를 실제로 지키도록 돕는 로컬 웹앱입니다.

- 종목이 단계를 차례로 통과합니다: 아이디어 → 1차 필터 → 심층 분석 → 가치평가 → 투자 메모 → 매수 대기 → 보유 → 매도 → 복기 완료 (별도로 탈락)
- 각 단계의 판단을 기록으로 남기고, 게이트를 우회하면 그 사유도 남깁니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
cp .env.example .env
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 데이터는 `data/app.db`(SQLite)에 저장됩니다.
